# CodeAlpha_TaskAutomation

## ⚙️ Task Automation with Python Scripts
A Python script that automates a small, real-life repetitive task, built for
the **CodeAlpha Python Programming Internship**.

### 📌 What it does
Scans a `.txt` file, extracts every email address it contains using regular
expressions, removes duplicates, and saves the unique results to a new
output file.

### 🧠 Concepts Used
`re`, file handling

### ▶️ How to Run
```bash
python3 task3_extract_emails.py
```
You'll be prompted for the input `.txt` file path and an output file name.
